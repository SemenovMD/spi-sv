# AXI-Lite SPI Master

Данный модуль реализует SPI Master с управлением через интерфейс AXI-Lite на SystemVerilog. Позволяет осуществлять обмен данными по SPI с внешними устройствами, используя стандартный AXI-Lite интерфейс для конфигурирования и передачи данных.

## Особенности
- Поддержка стандартного SPI Master (MOSI, MISO, SCLK, CS).
- Управление и обмен данными через AXI-Lite Slave интерфейс.
- Настраиваемая частота SPI.
- Настраиваемая частота тактирования модуля.

## Параметры
- `AXI_DATA_WIDTH` — ширина данных AXI-Lite (по умолчанию 32).
- `AXI_ADDR_WIDTH` — ширина адреса AXI-Lite (по умолчанию 32).
- `CLOCK` — частота системного тактирования (по умолчанию 100 МГц).
- `SPI_CLOCK` — частота тактирования SPI (по умолчанию 5 МГц).

## Симуляция
Для симуляции используется `QuestaSim`. Убедитесь, что путь к исполняемому файлу `vsim` добавлен в файл `bashrc`.

Для запуска полной симуляции выполните команду:
```sh
make sim
```

Для очистки файлов, полученных при симуляции, выполните команду:
```sh
make clean
```

## Документация

### `axil_spi_master`
Основной модуль SPI Master с управлением по AXI-Lite. Содержит три конечных автомата (FSM) для обработки AXI-Lite записи, чтения и обмена по SPI.

### `axil_if`
Интерфейс AXI-Lite для подключения к внешней шине.

### `axil_spi_master_wrapper_sv`
Промежуточная оболочка на SystemVerilog для последующей обертки в Verilog.

### `axil_spi_master_wrapper_v`
Оболочка на Verilog для удобного использования в блок дизайне (IP Integrator).

### `axil_spi_master_tb`
Тестбенч для проверки работы модуля, включая генерацию AXI-Lite транзакций и эмуляцию SPI-периферии.

### `pkg_tb`
Пакет с параметрами и вспомогательными структурами для тестбенча.
